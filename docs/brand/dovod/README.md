# Dovod — направления логотипа

**Бренд в приложении:** утверждено плотное написание без разреза. [Экраны и проверка ребрендинга](application/README.md). Готовые ресурсы находятся в `frontend/public/brand`, общий компонент — `frontend/components/BrandLogo.vue`.

**Новый раунд: [жирные шрифтовые варианты без знака](type/index.html).** Три написания на основе Bricolage Grotesque, Syne и Basteleur, SVG и источники — в [type/README.md](type/README.md).

Откройте `index.html` в браузере: два выбранных варианта, переключение фона, образцы в 16/24/32 px и скачивание подходящей светлой или тёмной версии. Страница работает локально без сервера и сетевых запросов.

`overview.svg` — самостоятельный лист сравнения. `overview.png` — его растровое превью.

## Направления

1. **01-dialogue / Диалог.** D с хвостом реплики заменяет первую букву в названии: знак + `ovod`. В логотипе геометрия D оптически подстроена под толщину линий остальных букв; у отдельной иконки сохранена более плотная форма для маленьких размеров.
2. **02-grounding / Основание.** Исходный вариант первого раунда, сохранён в комплекте. На странице сравнения больше не показывается.
3. **03-perspectives / Две стороны.** Зеркальные формы и общий центр. Геометрия поддерживает палиндром `dovod` и сопоставление позиций.

## Файлы каждого направления

- `mark.svg` — знак с прозрачным фоном, квадратный viewBox 96 × 96.
- `mark-inverse.svg` — светлый знак для тёмного фона.
- `logo.svg` — логотип с авторским написанием, прозрачный фон. У первого направления знак заменяет начальную D; у третьего расположен рядом с полным словом.
- `logo-inverse.svg` — светлая версия логотипа.
- `app-icon.svg` — иконка на тёмном скруглённом фоне, viewBox 128 × 128.

`wordmark.svg` и `wordmark-inverse.svg` — общее написание dovod отдельно от знака.

## Геометрия и цвет

Все знаки и буквы нарисованы SVG-контурами. Шрифты, растровые изображения, маски, фильтры, скрипты и внешние ресурсы в самих логотипах не используются. Для изменения цвета замените значение `fill` у корневого SVG; у иконки фон и знак имеют отдельные цвета.

- Тёмный зелёный: `#243D32`.
- Тёплый светлый: `#F6F3EC`.
- Цвет служит для сравнения направлений и пока не является окончательной палитрой продукта.

Поля встроены в viewBox знаков и логотипов. При применении оставляйте свободное пространство вокруг видимого знака не меньше четверти его высоты. Сначала проверьте нужный размер на целевом фоне; образцы 16/24/32 px есть на странице сравнения.

Это варианты для выбора визуального направления.
