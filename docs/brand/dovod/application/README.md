# Dovod — применение бренда

Основной логотип: плотный Bricolage Grotesque 800, без разреза и без отражения букв. Исходник — [01-ink.svg](../type/01-ink.svg); компоненты приложения используют те же векторные контуры.

Весь интерфейс использует общие цвета, типографику, кнопки и состояния. Светлая тема: тёплая бумага и зелёные чернила. Тёмная: почти чёрный фон, нейтральные серые поверхности и светлый текст; зелёный остаётся акцентом. Нейтральные цвета выбраны по [палитре GitHub Primer](https://github.com/primer/primitives/blob/main/src/tokens/base/color/dark/dark.json5). Кнопки входа и регистрации компактные, по содержимому.

Переключатель в навигации и на формах сохраняет выбор. Общие переменные применяются к карточкам, диалогам, настройкам, графам, Mermaid и Markdown-редактору. Изменение темы сохраняет черновики и положение диаграммы.

Тексты интерфейса используют **Projects → Documents**. Переписаны начало работы, подсказки, пустые состояния, настройки, команды, общий доступ и экспорт. Обоснование и словарь — [язык интерфейса](../copy.md).

Последние правки: Methodologies — компактный список с описаниями, раскрываемыми условиями и кнопкой Copy prompt для каждой методологии. Промпт включает ссылку `/llms.txt` и идентификатор выбранного варианта. Разделители доходят до краёв контейнера; отступы заданы в строках. Список Teams убран из Settings. В проекте Updates показывается только при непрочитанных документах, без текстовой подписи; Roadmaps, Mind map и Knowledge graph перенесены в меню. Усиленные обводки тёмной темы приглушены до `#3d444d`, клавиатурный фокус сохраняет акцентный цвет.

## Проверка

- `npm run generate` и `npm run build-storybook` — успешно.
- `node scripts/css-consistency.mjs` — без ошибок.
- `go test ./cmd/... ./internal/...` — успешно.
- Chrome после обновления текстов: реальный вход, Projects, All documents, Document/Source, подпись Marks, настройки, Sessions, Teams, Methodologies и API reference; ширины 320, 390 и 1440 px.
- Chrome: ширины 320, 390, 768 и 1440 px; прямые ссылки на обе формы; компактные кнопки; показ пароля; валидация; повторная отправка; ошибки и повторная попытка; сохранение адреса перехода; закрытая регистрация и приглашение; отклонение внешнего адреса перехода.

Браузерные проверки поведения использовали изолированные ответы API; отдельно проверен настоящий вход в локальный тестовый сервер. В обеих темах проверены контраст текста и статусов (не менее 4.5:1), сохранение выбора после перезагрузки, черновик Markdown-редактора, обновление Canvas и Mermaid без сброса масштаба.

`make build-all` собирает приложение с актуальным встроенным UI. После проверки текущая сборка скопирована в `internal/api/static` тем же способом, что использует `frontend-embed`.

Проверка последних правок в Chrome: копирование разных методологий, одинаковый промпт в списке и на странице методологии, реальная загрузка `/llms.txt`, отказ буфера обмена и возврат фокуса, поиск, раскрытие условий, разделители до границ контейнера, ширины 320/390/1440 px, Settings без Teams, приглушённые обводки, Updates со счётчиком 0 и 3, пункты меню проекта и его мобильная ширина. Сборки приложения и Storybook успешны.

Ветка PR дополнительно проверена с отдельной базой на текущем API: инструкции проекта доступны в Overview, память отображает существующий массив строк. Изменения отдельного API памяти в ребрендинг не входят.
